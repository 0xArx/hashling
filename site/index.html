Everything it watches

COR

It connects the dots

One odd signal is usually noise. Hashling links signals that involve the same program into one storyline: it arrived as a download, ran, set itself to start automatically, then started checking in with a server. Open any app for a dossier that combines its signature, Apple's verdict, malware databases, who launched it, every server it contacted this week and the permissions it holds, scored with the reasons shown. A daily briefing tells you what is new compared with what is normal for your Mac.

ASK

Ask about anything, get a straight answer

Every item in the dashboard has an Explain button. Your own AI checks the facts with Hashling, tells you in plain English whether it is dangerous and what to do, and can prepare the fix for you to approve with Touch ID. Each area also shows a clear "nothing suspicious found" or exactly what it found.

NET

Live network connections

Every app's active connections with upload and download rates, who owns each destination, and an alert when an app reaches a host it has never contacted before. Flags unsigned programs running from Downloads or temp folders that are talking to the internet, and warns when the Wi-Fi is open, your router's identity changes, or your DNS is switched.

MAL

Malware scanning

On-demand and routine scans using ClamAV with Cisco Talos signatures, YARA-X running Apple's own XProtect rules, and osquery packs built for known Mac malware. Scan any file, folder, or your whole Downloads directory on a schedule.

PER

Persistence watch

An alert the moment something new installs itself to run at startup. Launch agents, login items, launch daemons, and browser extensions, all watched in real time. Modeled on the approach used by KnockKnock and BlockBlock.

TRK

Who's tracking you

Nearby Bluetooth trackers that keep following you as you move, and a live view of which apps hold access to your location, camera, microphone, screen recording, accessibility, and full disk. Updated as permissions change.

PST

Security posture score

A scored review of the settings that matter most: FileVault, firewall, SIP, Gatekeeper, XProtect freshness, pending OS updates, auto-login, guest account, system proxies, custom root certificates, MDM profiles, and installed remote-access tools.

AGT

AI agent capabilities

Finds every AI agent on your Mac and shows, per agent, what it can actually do: its MCP servers and tools, whether it runs in auto-approve mode, its macOS permissions, API keys sitting in plain text in config files, and its live network activity.

BEH

Behaviour over time

Every program that runs, who started it, and whether it used a technique Mac stealers rely on, like fake password prompts, keychain dumps or reading browser cookies. Apps that check in with a server on a fixed clock, and sudden large uploads, are flagged against each app's own normal.

DL

Downloads, apps and keys

Where every new file and app came from, whether Apple notarized it, and whether its fingerprint is known malware. Live threat feeds check every connection. Hashling also finds API keys left in shell history and config files, and outdated software with known holes.

OPT

Storage and speed

What fills your disk, caches that rebuild themselves, apps you have not opened in months, leftovers from deleted apps, exact duplicate files, and what starts with your Mac and how much memory it costs. Your AI can draft a cleanup plan; files only ever go to the Trash, after Touch ID.

LOG

Live dashboard and timeline

A dashboard at hashling.localhost, right on your Mac, explains every finding in plain English, not security jargon. A timeline shows what changed and when, so you can trace any event back to its source without digging through system logs. Accessible from any browser on your Mac.

Built on tools security professionals trust

Hashling does not reinvent the wheel. It connects open-source engines already used in professional security work and adds the local context and plain-English explanations that make them usable day to day.

ClamAV

Open-source antivirus engine maintained by Cisco Talos, with continuously updated signatures for malware, trojans, and exploits across Mac and other platforms.

YARA-X

Pattern-matching engine for identifying malware families. Hashling ships with Apple's own XProtect YARA rules from macOS, plus community packs targeting Mac-specific threats.

Apple XProtect

Apple's built-in malware signature system, expressed as YARA rules and shipped with every Mac. Hashling runs these rules directly so you get the same detection Apple uses.

osquery

Open-source tool for querying your operating system as a relational database. Hashling uses it for threat-hunting packs built around known Mac malware indicators of compromise.

Open threat feeds

Known-bad servers and domains from abuse.ch (Feodo Tracker, ThreatFox, URLhaus), Spamhaus DROP, Emerging Threats and FireHOL, refreshed every few hours and checked locally against every connection.

Proven techniques

Beacon timing from RITA, live startup-item watching in the style of BlockBlock, file reputation from Team Cymru and CIRCL, YARA-Forge community rules, and the safe-cleanup rules of Mole, Pearcleaner and czkawka.

What stays on your Mac, and what does not

Stays on your Mac

  • All monitoring data and event logs
  • Scan results and threat findings
  • Network connection history
  • Security posture readings
  • Agent capability records
  • Dashboard and timeline

May leave your Mac

  • DNS lookups to resolve who owns an IP address (you can disable this)
  • Signature updates from ClamAV and YARA rule repositories, and threat-feed downloads from abuse.ch, Spamhaus and FireHOL
  • For new downloads and apps you investigate, a file fingerprint (SHA-1 hash, never the file) is checked with Team Cymru and CIRCL
  • When you ask an AI for help, your question and the Hashling data it looks up go to that AI’s company (for example Anthropic, OpenAI or Google), under their privacy terms. You pick the AI you trust, and nothing is sent unless you ask.

Hashling has no account, no cloud backend and no telemetry. Your AI agent sees only what it requests through Hashling’s tools, and it can never change anything without your Touch ID.

Questions

Does Hashling replace antivirus?

No. Hashling complements XProtect, the malware detection Apple ships with every Mac, by running ClamAV and YARA-X on top of it. It is not a kernel-level endpoint detection product and does not replace the on-access scanning a commercial EDR provides. If your threat model requires a commercial EDR, use one alongside Hashling.

Does my data leave my Mac?

Hashling itself only downloads: malware signatures, lists of known bad servers, and lookups of who owns an internet address (you can turn those off). For new downloads it checks a file fingerprint, never the file. The one thing that sends your information somewhere is AI help: when you ask an AI, your question and the Hashling data it looks up go to that AI’s company. You choose which AI you trust, and nothing is sent unless you ask. Hashling sends no telemetry, crash reports or analytics.

Which AI agents work with Hashling?

Any client that supports the Model Context Protocol. That includes Claude, Cursor, Codex, and anything else built on MCP. Hashling also exposes a local HTTP API if you want to call it directly from scripts or custom tooling.

What can the AI agent actually do?

The agent is read-only. It can retrieve network activity, findings, persistence items, permissions, nearby trackers, system posture, process information, and run read-only osquery SQL. It can also submit a proposed action, but the proposal only appears in your dashboard. Nothing executes until you approve it with Touch ID.

How does the AI agent capability monitoring work?

Hashling reads each agent's configuration files at known paths, parses them for MCP server declarations, permission mode flags, hooks, and plaintext credentials, then correlates that configuration with live network connections and macOS permission grants from the Privacy and Security settings database. Nothing is sent anywhere. The capability card is built entirely from local data.

Is Hashling always running in the background?

Yes. Hashling installs a lightweight daemon that collects network events, watches for persistence changes, and keeps the dashboard up to date. You can pause or stop it from the dashboard or the menu bar icon.

What macOS version do I need?

Hashling requires macOS 14 Sonoma or later on Apple silicon. Intel Mac support is not available in the current release.
